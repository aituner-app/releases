# aituner releases

Signed and notarized downloads of [aituner](https://aituner.app) for Apple Silicon Macs (M1 or later, macOS 14 or
later), and the notes for every release: see [Releases](../../releases).

- **Homebrew:** `brew install --cask aituner-app/tap/aituner`
- **Disk image:** download `aituner_v<version>.dmg` from the latest release, open it and drag aituner to Applications.
- Every release lists SHA-256 checksums in `SHA256SUMS`.

aituner updates itself (it asks first) from here. Bugs go to [aituner-app/issues](https://github.com/aituner-app/issues),
or use **Report a bug** in the app.
